We develop Skill Abstraction from Optical Flow (SOF), a framework that learns reusable robot skills directly from action-free videos. By using optical flow as a surrogate for action, the system extracts and composes skills without relying on labeled datasets. It plans in a learned skill space and translates flow-based plans into executable actions, improving multitask and long-horizon performance using only raw visual data.
